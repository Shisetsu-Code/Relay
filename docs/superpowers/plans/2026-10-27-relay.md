# Relay Implementation Plan

> **For agentic workers:** The user requested implementation and publication directly. Work in disjoint files, integrate and review before publishing. Use meaningful test-first checks for behavioral changes.

**Goal:** A runnable local HTTP/HTTPS relay with HAR import and full traffic inspection.

**Architecture:** Pinned mitmweb engine; a strict HAR compatibility adapter; a passive diagnostic addon; a launcher that confines listeners and capture files locally.

**Tech Stack:** Python >=3.12, mitmproxy==12.3.1, unittest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-27-relay-design.md`.

## Constraints and review focus

- Never commit real HARs, secrets, CA private keys or captures.
- Loading a HAR must not issue network requests; missing bodies must not become empty replayable bodies.
- No request/response rewriting by the passive addon; binary and duplicate headers matter.
- Loopback UI authentication and native TLS verification remain enabled.
- No actual Ganamos traffic in tests; report live limits honestly.

## Tasks

- [x] Implement and test the strict HAR import adapter; wire it into both native FlowReader references.
- [x] Implement the launcher, local capture configuration and reverse mode option; test emitted engine options.
- [x] Implement and test passive diagnostics and offline raw export.
- [x] Run a real engine against controlled HTTP/HTTPS upstreams and verify body/header fidelity, UI import and manual replay.

## Evidence and publication

The final local suite passed 65 tests. The supplied Ganamos HAR imported 327 network flows from 377 entries; 50 embedded data resources were explicitly omitted. No request from that HAR was sent. The independent review's HTTP/2 version and framing findings were fixed and rechecked. Details are in `docs/verification.json`, `docs/har-import-verification.json` and `docs/publication-scan.json`.

The repository's Actions workflow verifies the published commit on Linux and Windows. Its remote status is the authoritative CI result; the final delivery reports the commit and run URLs.
